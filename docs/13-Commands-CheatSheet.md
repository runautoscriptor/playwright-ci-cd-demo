# 13. Commands Cheat Sheet

## Git Commands

```bash
git init
git clone <repo-url>
git add .
git commit -m "message"
git push origin <branch>
git pull origin <branch>
git fetch origin
git merge <branch>
git rebase <branch>
git stash
git log
git branch
git checkout <branch>
git switch <branch>
git restore <file>
git reset --soft HEAD~1
git revert <commit-hash>
```

## Playwright Commands

```bash
npx playwright test
npx playwright test --headed
npx playwright test --grep "login"
npx playwright show-report
npx playwright test --trace on
npx playwright test --ui
```

## npm Commands

```bash
npm install
npm install -D @playwright/test
npm ci
npm test
```

## GitHub Actions Commands

```bash
git push origin <branch>
# GitHub Actions runs automatically on push/PR
```

## Important Notes
Keep this cheat sheet handy for quick revision before interviews or live coding sessions.
