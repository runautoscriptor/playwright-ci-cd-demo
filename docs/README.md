# Interview Handbook: Playwright + Git + GitHub + CI/CD + QA Automation

This document is a personal interview handbook for QA automation, Git, GitHub, CI/CD, and Playwright. It is intentionally beginner-friendly, professional, and easy to revise before interviews.

## Purpose

Use this handbook to:
- understand Git and GitHub workflows clearly
- prepare for Playwright automation interviews
- learn CI/CD and GitHub Actions step by step
- connect testing practices to real-world QA work

## Quick Interview Summary

| Topic | What to Remember |
|---|---|
| Git | Track changes, collaborate, safely manage versions |
| GitHub | Host repositories, review code, manage PRs |
| Branching | Never work directly on main in professional teams |
| Playwright | Automate browser-based web tests reliably |
| POM | Keep tests clean and reusable |
| CI/CD | Build confidence with automated validation |
| Regression Testing | Protect existing features from new bugs |
